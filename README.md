# agent-skills

Claude Code plugin(s) for Dockstore (SEAB-7802).

## dockstore

Skill plus MCP server config for searching and inspecting tools, workflows and notebooks on Dockstore.

- Production MCP endpoint: `https://dockstore.org/mcp` (configured in `.mcp.json`)
- QA/development endpoint: `https://qa.dockstore.org/mcp`

Try locally: `claude --plugin-dir .`
